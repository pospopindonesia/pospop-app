Setup Kasir POSPOP Anda

Ikuti 5 langkah sederhana untuk mengaktifkan sistem kasir berbasis Google Drive Anda.

Download PDF
1 Persiapan File
Penting: Jangan download/upload ulang. File akan gagal jika tidak berjalan di ekosistem Google Drive.
  • Buka link Google Drive yang Anda terima.
  • Klik kanan app.pospop dan database, lalu pilih Buat Salinan.
  • Pastikan salinan ada di Drive Saya.
  • Rapikan kedua file tersebut ke dalam satu folder baru.
2 Deploy Aplikasi
  • Buka file app.pospop (Anda akan diarahkan ke Google Apps Script).
  • Klik Deploy > Deployment Baru.
  • Pilih Jenis: Aplikasi Web.
  • Setel "Jalankan sebagai": Siapa saja yang memiliki akun Google.
  • Klik Deploy dan Salin URL Aplikasi Web yang muncul.
3 Setup Database
  • Buka URL Aplikasi yang baru Anda salin.
  • Izinkan akses keamanan Google (Pilih email > Lanjutkan ke app.pospop).
  • Salin URL file database (Spreadsheet) Anda.
  • Tempelkan ke kolom Link Google Spreadsheet di aplikasi.
  • Klik Hubungkan Spreadsheet.
4 Login Pertama
  • Isi Nama Toko, User Admin, dan Password (perhatikan huruf besar/kecil).
  • Klik Inisialisasi Sistem.
  • Klik Masuk Dashboard untuk memulai.
5 Aktivasi
  • Buka menu Pengaturan di dalam aplikasi.
  • Klik Aktivasi Sekarang.
  • Admin akan memproses aktivasi Anda (maksimal 24 jam).
